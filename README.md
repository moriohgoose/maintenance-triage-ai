# AI-ассистент первичной обработки заявок на ремонт оборудования

Приложение принимает текстовую заявку сотрудника о неисправности промышленного
оборудования и превращает её в структурированную карточку: оборудование,
симптомы, характер неисправности, приоритет, ответственная служба и
рекомендуемые действия. Если информации не хватает, приложение задаёт
уточняющие вопросы.

## Ключевая идея архитектуры

**Языковая модель понимает текст, решения принимаются по правилам.**

| Задача | Кто решает |
|---|---|
| Извлечь из свободного текста оборудование, симптомы, состояние, признаки опасности | LLM (YandexGPT) |
| Найти оборудование в справочнике | Код |
| Определить приоритет | Правила: критичность оборудования × состояние + корректирующие правила |
| Назначить ответственную службу | Правила маршрутизации |
| Решить, нужны ли уточнения | Правила: проверка обязательных данных |
| Сформулировать рекомендации | LLM, опираясь на справочник типовых действий |

## Структура проекта

```
data/                 справочники
  equipment.yaml      оборудование, его критичность и типовые проверки
  departments.yaml    подразделения
  rules.yaml          правила приоритета, маршрутизации и уточнений
  actions.yaml        типовые первичные действия
core/                 логика обработки
  schema.py           схема данных (Pydantic)
  catalog.py          загрузка справочников
eval/
  golden_set.yaml     эталонная разметка 21 заявки для проверки качества
tests/                автотесты
```

## Запуск тестов

Нужен Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pytest -v
```
